# 🧪 OOD Trap Test Evaluation Report (v5)

**Evaluation Configuration**:
- **Total Samples:** 30
- **Trained (Gen 1-2):** 30 (80%)
- **Untrained Val (Gen 3+):** 6 (20%) - Curated Trap Cases

## 🔍 Executive Summary
This evaluation tested the generalization of the Tuned model against Vanilla and RAG baselines.

### Key Findings
1.  **Hallucination in Tuned Model**: The Tuned model performs well on trained (Gen 1-2) data but severely **hallucinates on untrained (Gen 3+) "Trap" cases**. It often confidently assigns incorrect Gen 1-2 names (e.g., calling *Lickilicky* "Gastly" or *Munchlax* "Dugtrio").
2.  **RAG Robustness**: Even with the strict "Gen 1-2 only" filter, RAG generally retrieves **visually similar** valid Pokemon (e.g., retrieving *Snorlax* for *Munchlax*, *Electabuzz* for *Electivire*). This provides useful context/hints compared to the Tuned model's confident misinformation.
3.  **Vanilla Weakness**: The Vanilla model accurately identifies general concepts but struggles with specific Pokemon names (often defaulting to "Zoroark" or generic descriptions) and fails completely at Korean naming.
4.  **Conclusion**: Tuning successfully adapts the model's style/format but does not magically inject knowledge for unseen entities. **RAG is essential** for handling new/unseen data reliably.
