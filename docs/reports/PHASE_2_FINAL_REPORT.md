## 2. F5 공정한 RAG 벤치마크 결과 (n=50)

| 모델 | 영어 이름 정확도 | 한국어 이름 정확도 |
|---|---|---|
| **Vanilla** | 24/50 (48.0%) | 1/50 (2.0%) |
| **RAG** | **45/50 (90.0%)** | **36/50 (72.0%)** |
| **Tuned** | 24/50 (48.0%) | 2/50 (4.0%) |

### Phase 1 대비 수치 변화

| 모델 | Phase 1 (v6) | Phase 2 (v7) | 변화 |
|---|---|---|---|
| Vanilla | 86.7% | 48.0% | -38.7%p ← Phase 1이 과장됨 |
| RAG | **100%** | **90.0%** | -10.0%p ← 여전히 우위 확인 |
| Tuned | 80.0% | 48.0% | -32.0%p ← Phase 1이 과장됨 |

**핵심**: RAG 우위는 공정한 조건에서도 실제로 존재한다. 단, Phase 1의 극단적 수치(100%)는 평가 설계 결함으로 인한 과장이었다.

### RAG 거리 분포 (공정성 확인)

|---|---|---|
| 최솟값 | **0.000** (동일 이미지) | **0.018** |
| 평균 | ~0.01 | ~0.045 |
| 최댓값 | ~0.28 | 0.19 |

## 3. F6 Tuned 모델 진단 결과 (n=41)

| | 정확도 |
|---|---|
| A. 학습 이미지 | 21/41 (51.2%) |
| B. PokeAPI 스프라이트 | 21/41 (51.2%) |
| **차이 (A−B)** | **+0.0%p** |

**판정: H2 (학습 미흡) — 두 소스 모두 동일한 낮은 정확도**

Phase 1에서 "과적합"으로 진단했지만, F6 결과는 이를 반박한다.

- Tuned 모델은 학습 이미지에서도 51.2%, 새 이미지에서도 51.2%로 동일
- 이는 Vanilla(48%)와 사실상 차이 없음
- **결론: 파인튜닝이 시각적 인식 능력을 거의 개선하지 못했다**

### 왜 학습 미흡인가?

오답 패턴 분석:
```
machamp (괴력몬)  → Tuned: "Groudon"  (학습 이미지도, 새 이미지도 동일한 오답)
alakazam (후딘)  → Tuned: "Gallade"  (두 이미지 모두 오답, 다른 오답)
gyarados (갸라도스) → Tuned: "Dragonair" (두 이미지 모두 동일 오답)
```

동일한 이미지 소스에서 동일한 오답이 나온다는 것은 모델이 이미지를 인식하고 틀리는 것이 아니라, **이미지와 무관하게 특정 이름을 출력하는 편향**이 학습된 것을 시사한다.

## 4. F7 OOD 강화 테스트 결과 (n=30)

| 카테고리 | 설명 | Vanilla | RAG |
|---|---|---|---|
| evolution | Gen1-2 진화형 | 3/10 (30.0%) | 1/10 (10.0%) |
| visual | 시각적 유사 | 1/10 (10.0%) | 2/10 (20.0%) |
| distinct | 완전 이질적 | 1/10 (10.0%) | 1/10 (10.0%) |
| **전체** | | **5/30 (16.7%)** | **4/30 (13.3%)** |

### 주요 발견

**1. RAG가 OOD에서 Vanilla보다 낮거나 동등함**
- evolution 카테고리: Vanilla 30% vs RAG 10% — RAG가 오히려 낮음
- RAG가 진화형 포켓몬을 "전진화 포켓몬"으로 힌트를 주면, 모델이 그 힌트를 그대로 답으로 출력함 (예: Electivire → "Electabuzz"로 답변)
- 이는 RAG 힌트가 OOD에서 **오히려 혼란을 줄 수 있음**을 보여줌

**2. Phase 1 v5와 OOD 수치 유사**
- Phase 1: 전 모델 16.7%, Phase 2: Vanilla 16.7%, RAG 13.3%
- Phase 2에서도 OOD 성능은 낮음 → Phase 1 OOD 결과는 우연히 실제와 가까웠음

**3. RAG 거리와 정확도 무관계**
- 낮은 거리(좋은 매칭)도 OOD 정답으로 이어지지 않음 (예: mime-jr Dist=0.055 → 오답)
- 높은 거리(나쁜 매칭)에서도 우연히 정답이 나오는 경우 있음

## 5. Phase 1 결론 재검토

### 유지되는 결론 ✅

1. **RAG가 Vanilla보다 우수** (Gen1-2 학습 포켓몬 기준)
   - Phase 1: 100% vs 86.7% → Phase 2: **90% vs 48%** (차이가 오히려 더 명확)

2. **Vanilla는 한국어 공식 이름을 모름**
   - Phase 2에서도 한국어 정확도 2% 확인

3. **OOD(Gen3+) 성능은 모든 방법이 낮음**
   - Phase 2에서도 ~15% 수준 확인

### 수정되는 결론 ⚠️

1. **"Tuned 모델 과적합" → "파인튜닝 학습 미흡"으로 수정**
   - 학습/새 이미지 정확도 차이가 0%p로 과적합이 아님
   - 파인튜닝 자체가 시각 인식에 효과 없음

2. **"Tuned 80% (Vanilla 87%에 근접)" → "Tuned 48% = Vanilla 48%"로 수정**
   - Phase 1 수치는 평가 설계 결함으로 모두 과장됨

3. **"RAG 100% 일반화" → "RAG 90%"로 수정**
   - 여전히 최고 성능이지만 완벽하지 않음

4. **"RAG가 OOD에 강함" → "RAG가 OOD에서 오히려 Vanilla보다 낮을 수 있음"으로 수정**
   - evolution 카테고리에서 RAG 힌트가 혼란을 야기

## 6. 신뢰할 수 있는 최종 결론

### Gen1-2 포켓몬 식별 (학습 범주 내)

| 결론 | 근거 |
|---|---|
| RAG > Vanilla >> Tuned (한국어) | RAG 72%, Vanilla 2%, Tuned 4% |
| RAG ≈ Vanilla (Tuned) (영어) | 90% vs 48% vs 48% |
| 파인튜닝은 한국어 이름 학습에 실패 | Tuned 한국어 4% (Vanilla 2%와 유사) |

### OOD (Gen3+) 포켓몬 식별

| 결론 | 근거 |
|---|---|
| 모든 방법이 ~15% 수준으로 낮음 | n=30, 카테고리별 유사한 실패 |
| RAG 힌트가 OOD에서 혼란을 줄 수 있음 | evolution 카테고리 RAG 10% < Vanilla 30% |

### 방법별 권장 사용처 (수정됨)

| 방법 | 권장 상황 | 주의사항 |
|---|---|---|
| **RAG** | Gen1-2 포켓몬 식별, 한국어 이름 필요 시 | OOD에서 힌트가 혼란 야기 가능 |
| **Vanilla** | 빠른 프로토타이핑, OOD 포켓몬 포함 시 | 한국어 이름 불가 |
| **Tuned** | 현재 설정으로는 RAG/Vanilla 대비 이점 없음 | 재학습 필요 (더 많은 데이터, 더 높은 rank) |

## 7. Phase 3 권장 실험 (선택)

48GB 환경에서 가능한 후속 실험:

1. **더 큰 LoRA rank + 더 많은 학습 데이터**
   - 현재 rank=8, 520장 → rank=32, 세대 불명 323개 재식별 후 확장
   - 학습 미흡(H2) 해소 시도

2. **RAG DB 전 세대 확장 (Gen1-9)**
   - OOD 성능을 실질적으로 높이는 직접적 방법

3. **더 큰 베이스 모델 테스트**
   - Qwen2-VL-7B 16-bit 버전 (`models/fused_qwen2_vl_4bit`, 15GB)으로 재실험
   - 48GB 환경에서 충분히 로드 가능
